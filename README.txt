Гайд «Старт работы в ChatGPT» — Эссенс.Ai
==========================================

Что в архиве:
- index.html — страница гайда (166 КБ)
- img/ — 27 картинок в формате WebP (~1 МБ), подгружаются лениво

Как опубликовать (инструкция для Claude Code):
1. Положить index.html и папку img/ рядом, в одну директорию хостинга
   (корень домена или любая подпапка, например /start-chatgpt/).
2. Больше ничего не нужно: сборки нет, база данных не нужна, все пути
   относительные — страница работает из любой подпапки.
3. Шрифты вшиты в HTML, внешних зависимостей нет.

Проверка после публикации: страница открывается, картинки в шагах видны,
кнопка «Показать другой адрес» листает адреса, отметки «Готово» сохраняются
после перезагрузки страницы.

Текущая опубликованная копия для сверки: https://tsyrocoach-metod.github.io/kleyman/
